# رصيد — حزمة البداية

## التجهيز (مرة واحدة)
1. أنشئ مستودعاً جديداً على GitHub، وفكّ هذه الحزمة في جذره.
2. انسخ مجلد `rased-mockups` (النماذج المعتمدة على جهازك) إلى جذر المستودع نفسه.
3. تأكد أن `.gitignore` موجود قبل أول commit. مجلد `data/` لا يُرفع أبداً.
4. افتح Claude Code في جذر المستودع، وألصق برومبت البداية.

## المحتويات
| الملف | الغرض |
|---|---|
| SPEC.md | ورقة الاتفاق المعتمدة v1.0 |
| CLAUDE.md | الحقائق المقفلة. تُقرأ أول كل جلسة |
| DECISIONS.md | سجل القرارات، إلحاقي فقط |
| PROGRESS.md | أين توقفنا. يُحدَّث آخر كل جلسة |
| CHOSEN.md | نظام التصميم المعتمد بقيمه الدقيقة |
| FIELDS.md | مواصفات حقول الإدخال حسب نوعها |
| KNOWN-ISSUES.json | البيانات المعروفة للتعديل اليدوي، وأرقام المطابقة |
| BUILD-PROMPT.md | خطة البناء بمراحلها وقواعدها |
| reports/ | تقارير RTL للقراءة: ورقة الاتفاق ومراجعة البيانات |
| data/ | ملف الإكسل المشفّر (كلمة المرور لا تُكتب في أي ملف) |
| private/ | **خارج git.** الأصل الحرفي بالبيانات الحقيقية (KNOWN-ISSUES، تقرير مراجعة البيانات، اللقطات الأصلية، خريطة الأكواد). المستودع عام، فلا يُرفع أبداً |

> المستودع عام: أسماء الموردين في الملفات المرفوعة بأكواد «المورد (أ..ق)» والمبالغ مخفية أو وهمية. `reports/spec.html` نسخة الإصدار 1.0؛ المرجع المحدّث `SPEC.md` (1.1).

## التطوير (المرحلة 1)
| الأمر | ماذا يفعل |
|---|---|
| `npm ci` | تثبيت الاعتماديات من ملف القفل |
| `npm run dev` | خادم التطوير؛ معرض الحقول على `/__fields` (للتطوير فقط) |
| `npm run lint` / `npm run lint:css` / `npm run format:check` | ESLint (مع قاعدة منع العناصر الأصلية) وStylelint (خصائص RTL المنطقية) وPrettier |
| `npm run typecheck` | TypeScript |
| `npm test` | اختبارات الوحدة والمكونات (Vitest) |
| `npm run test:rules` | قواعد Firestore على المحاكي (يحتاج Java 11+) |
| `npm run test:e2e` | Playwright (Chromium محلياً؛ والمتصفحات الثلاثة في CI) |
| `npm run build` | بناء الإنتاج لـ GitHub Pages (CSP مضمّنة، والمعرض مستبعد) |
